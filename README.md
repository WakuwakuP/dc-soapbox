# dc-soapbox

[![Soapbox Build](https://github.com/WakuwakuP/dc-soapbox/actions/workflows/build-soapbox.yaml/badge.svg)](https://github.com/WakuwakuP/dc-soapbox/actions/workflows/build-soapbox.yaml)

Local builds: run `node prepare-guard.cjs` before `cd soapbox && yarn`. This routes the upstream Yarn lockfile's npm tarballs through Takumi Guard; credentials stay in your user npm configuration.
